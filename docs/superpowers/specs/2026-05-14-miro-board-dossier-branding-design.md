# Miro Board Dossier Branding Design

## Goal

Rename and reposition the project from a technical SVG reader into **Miro Board Dossier**, a user-friendly skill that helps agent users turn Miro boards into reusable context dossiers.

## Audience

The primary audience is people using agentic tools such as Codex, Claude Code, ChatGPT, Claude, and similar assistants. They may not be Python developers. The README should make the workflow feel approachable: export a board, ask the agent to use the skill, get a dossier.

## Product Positioning

Headline:

> Turn messy Miro boards into clear, reusable context for AI agents.

Core promise:

> Give your agent the same board context a careful human would build after opening Miro, reading the flow, tracing the arrows, spotting uncertainty, and writing a handoff.

## Naming

- Product name: `Miro Board Dossier`
- Skill slug: `miro-board-dossier`
- Repository name: `miro-board-dossier`
- Legacy install path compatibility is not required for the published package, but the README should describe the new path clearly.

## README Shape

1. Clear hero/header image.
2. Plain-language problem and outcome.
3. "Who this is for."
4. "What you get" with the dossier file list explained simply.
5. "How to use" for agent users first.
6. "Install" with `npx skills`.
7. Advanced CLI usage for technical users.
8. Honest limitations.

## GitHub Configuration

The repo should remain public with issues and PRs enabled. Protect `main` so changes go through PRs and direct branch changes are restricted to `pmilanez` where GitHub supports that for this account/repo.
